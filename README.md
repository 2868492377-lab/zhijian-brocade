# 织见 · 壮锦织造体验

一个可以旋转观察、亲手提经、穿梭与打纬的 3D 壮锦交互游戏。支持六幅内置纹样、上传更换图案、保存织造作品，以及带展品标注的壮锦展厅。

所有运行资源均内嵌在 `index.html` 中，文件小于 4 MB，无需安装依赖。

## 本地打开

下载 `index.html`，用支持 WebGL 的 Edge、Chrome 等现代浏览器打开即可离线体验。拖动场景环视，滚轮或双指缩放，点击按钮完成织造步骤；图案上传与进度保存在当前浏览器本机。

## 静态发布

GitHub Pages 使用本目录的 `index.html` 作为首页，`.nojekyll` 用于直接提供静态文件，无需构建。

Three.js 许可证见 `LICENSE-THREE.txt`。本游戏中的织机及工艺为数字交互示意。
